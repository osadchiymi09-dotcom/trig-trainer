# Тригонометрия — формулы и выводы

Интерактивный тренажёр по шпаргалке «Все формулы тригонометрии»:
конспект, **пошаговые выводы**, карточки (SRS), тесты, пропуски и ответы вслух.

Прогресс хранится отдельно для каждого логина в браузере.

## Режимы

- **Конспект** — формулы + блоки «Вывод»
- **Вывод** — открывай доказательство по шагам
- **Карточки / Тест / Пропуски / Вслух** — active recall

## Локальный запуск

```bash
python3 scripts/generate_content.py
npm install
npm run dev
```
