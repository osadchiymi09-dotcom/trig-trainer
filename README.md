# Материнские

Сайт для заучивания тригонометрических формул **через вывод из формул сложения**.

Только блоки со шпаргалки:
- сложение (матери)
- двойной / тройной угол
- понижение степени
- сумма ↔ произведение
- универсальная подстановка

https://osadchiymi09-dotcom.github.io/trig-trainer/

```bash
python3 scripts/generate_content.py
npm install
npm run dev
```
